# gtrwarrior

A repo containing guitar-specific information & resources to include text files, links, & possibly other types of data to support the practicing guitarist.

## Structure

This repository is organized into the following directories:

- `theory/`: Music theory concepts, scales, chords, etc.
- `techniques/`: Picking, fretting, and other guitar techniques.
- `songs/`: Chord progressions, tabs, and analyses of songs.
- `gear/`: Information about guitars, amps, pedals, and other equipment.
- `resources/`: Links to useful websites, books, and other resources.

## How to Contribute

To add new information to this repository, please follow these steps:

1.  Choose the appropriate directory for your content.
2.  Create a new file in that directory.
3.  Copy the content of `template.md` into your new file.
4.  Fill in the sections of the template with your information.
5.  Save the file and commit your changes.
