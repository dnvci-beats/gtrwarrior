# Harmonizing the Major Scale

## Description

Harmonizing the major scale means building a chord on each of its seven notes. This process is fundamental to understanding how chord progressions work and why certain chords sound good together. It's the foundation of diatonic harmony.

## Content

### The Process

To harmonize the major scale, you take each note of the scale as a root note and then stack two more notes on top of it, also taken from the scale. This is done by adding the third and fifth note above the root, using only the notes available in that key.

Let's use the C Major scale (C, D, E, F, G, A, B) as an example.

### The Diatonic Triads

When we harmonize the C Major scale with three-note chords (triads), we get the following sequence of chords:

-   **Chord I:** C Major (C-E-G)
-   **Chord ii:** D minor (D-F-A)
-   **Chord iii:** E minor (E-G-B)
-   **Chord IV:** F Major (F-A-C)
-   **Chord V:** G Major (G-B-D)
-   **Chord vi:** A minor (A-C-E)
-   **Chord vii°:** B diminished (B-D-F)

### The Chord Quality Pattern

This pattern of chord qualities is the same for EVERY major key:

-   **I - Major**
-   **ii - minor**
-   **iii - minor**
-   **IV - Major**
-   **V - Major**
-   **vi - minor**
-   **vii° - diminished**

(We use Roman numerals to represent the chords. Uppercase for major, lowercase for minor, and lowercase with a ° for diminished).

### Harmonizing with 7th Chords

We can also harmonize the scale with four-note chords (7th chords) by adding the 7th note above each root (again, using only notes from the parent scale). This gives us a richer, more complex set of chords that are very common in jazz, R&B, and pop music.

The pattern for diatonic 7th chords is:

-   **Imaj7** (e.g., Cmaj7)
-   **ii m7** (e.g., Dm7)
-   **iii m7** (e.g., Em7)
-   **IVmaj7** (e.g., Fmaj7)
-   **V7** (e.g., G7 - a dominant 7th chord)
-   **vi m7** (e.g., Am7)
-   **vii m7b5** (e.g., Bm7b5 - a half-diminished chord)

### Why is this important?

Understanding the diatonic chords in a key allows you to:
-   Figure out the chords to a song by ear.
-   Write your own chord progressions that sound musically "correct".
-   Improvise solos that fit the underlying harmony.
