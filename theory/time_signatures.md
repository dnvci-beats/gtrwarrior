# Time Signatures

## Description

A time signature is a notational convention used in Western musical notation to specify how many beats are contained in each measure, and which note value is equivalent to a beat. It's a fundamental concept for understanding rhythm in music.

## Content

### How to Read a Time Signature

A time signature consists of two numbers, one on top of the other, like a fraction.

-   **Top Number:** Tells you **how many beats** are in one measure.
-   **Bottom Number:** Tells you **what kind of note** gets one beat.

The bottom number corresponds to note values:
-   **2** = Half Note
-   **4** = Quarter Note
-   **8** = Eighth Note
-   **16** = Sixteenth Note

### Common Time Signatures

#### Simple Time

In simple time, the beat is divided into two equal parts.

-   **4/4 (Common Time):**
    -   Four beats per measure.
    -   The quarter note gets one beat.
    -   This is the most common time signature in popular music. You count it: "1, 2, 3, 4".

-   **3/4:**
    -   Three beats per measure.
    -   The quarter note gets one beat.
    -   This creates a waltz feel. You count it: "1, 2, 3".

-   **2/4:**
    -   Two beats per measure.
    -   The quarter note gets one beat.
    -   This feels like a march. You count it: "1, 2".

#### Compound Time

In compound time, the beat is divided into three equal parts, giving it a "triplet" or "swing" feel.

-   **6/8:**
    -   Six eighth notes per measure.
    -   The eighth note gets one beat, but the beats are grouped into two main pulses.
    -   It feels like two big beats, each divided into three. You count it: "**1**-2-3, **2**-2-3".
    -   Common in folk, blues, and some rock ballads.

-   **12/8:**
    -   Twelve eighth notes per measure.
    -   Grouped into four main pulses.
    -   This is the classic "slow blues" or "gospel" feel. You count it: "**1**-2-3, **2**-2-3, **3**-2-3, **4**-2-3".

### Odd Time Signatures

These are less common time signatures that create a more complex or "progressive" feel.

-   **5/4:** Five beats per measure (e.g., "Take Five" by Dave Brubeck).
-   **7/4:** Seven beats per measure (e.g., "Money" by Pink Floyd).
